# About the Agentic System

**BUS 4498 Team Build**

> **Problem to be solved**: The surf school's current scheduling process is disorganized and lacks transparency. Instructors have no visibility into lessons as they're booked, availability isn't systematically collected, and lesson assignments happen without a clear, reliable process.


## Team Charter

### Team Name

Dominioni Inc

### Team Members

Aidan Jones,
Alex Dominioni


### System Name

Lesson Scheduling Agent

### System Goal

The agentic system should read incoming booking emails, automatically add lessons to a shared Google Calendar, assign lessons to instructors based on their submitted availability, and send each assigned instructor a nightly summary email detailing their upcoming lessons, times, and headcounts.

### Who Is Better Off When This Works?
Surf instructors will be better off because they'll have clear, timely visibility into their schedules and lesson details instead of relying on a disorganized, manual process.
